Trei concepte de landing page

Ce e identic în toate trei

  • Hero cu mesaj și cifre-cheie
  • Despre companie
  • Servicii (6 poziții)
  • Opt avantaje
  • Proces în 6 pași
  • Comparator „înainte / după”
  • Calculator de termen (m² → zile)
  • Acoperire Moldova + Europa
  • Întrebări frecvente
  • Formular de ofertă + footer

Tehnic

  • Fonturi găzduite local (fără Google Fonts CDN)
  • Iconițe SVG desenate special pentru domeniu
  • Zero imagini externe — totul se încarcă de pe server
  • Animații la scroll, contoare, parallax
  • Responsive: 375 / 768 / 1024 / 1440 px
  • Respectă „prefers-reduced-motion”

Pasul următor, după alegere

  • Rescriere în React + Vite + Tailwind
  • Panou /admin pentru texte, poze și contacte
  • Fotografii reale de pe șantiere
  • Versiuni RO / RU (la cerere)
  • SEO + Google Business Profile
  • Deploy pe Cloudflare Pages + domeniu .md
